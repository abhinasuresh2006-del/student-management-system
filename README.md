Student Management System

A beginner-friendly Student Management System developed using Python.

Features

- Add student details
- View all students
- Search for a student
- Update student marks
- Delete student records
- Calculate average marks
- Save and load student data using JSON

Technologies Used

- Python
- JSON
- File Handling
- Exception Handling

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

python main.py

Project Purpose

This project was developed to practise Python programming, dictionaries, loops, conditional statements, file handling and JSON data storage.

Created as a BCA student project.
